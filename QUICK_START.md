# 🚀 Quick Start

Get the Klondike Solitaire game running in under 1 minute!

## Prerequisites

- Node.js 18.0.0 or higher
- npm

## Installation & Run

```bash
# 1. Install dependencies
npm install

# 2. Start the development server (opens in new window)
.\dev.ps1 start

# 3. Open your browser
# Navigate to: http://localhost:10010/
```

That's it! 🎉

## Alternative: Manual Start

If you prefer to see the server output in your current terminal:

```bash
npm run dev
```

Then open http://localhost:10010/ in your browser.
